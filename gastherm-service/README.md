# Gastherm Service

Εφαρμογή για πελάτες, εγκαταστάσεις και προγραμματισμό συντηρήσεων. Δουλεύει σε υπολογιστή και κινητό, με κοινά δεδομένα για όλους τους χρήστες: κάθε αλλαγή φαίνεται αμέσως στους υπόλοιπους.

## Τι κάνει

- **Σήμερα**: εκπρόθεσμες συντηρήσεις, ραντεβού ημέρας με διαδρομή στο Google Maps, ανοιχτά ραντεβού από προηγούμενες ημέρες, εγκαταστάσεις που θέλουν ραντεβού.
- **Πελάτες / Εγκαταστάσεις**: μητρώο με αναζήτηση (και με σειριακό αριθμό), φίλτρα κατάστασης, ιστορικό επισκέψεων.
- **Χάρτης**: όλες οι εγκαταστάσεις με χρώμα ανάλογα με την κατάσταση συντήρησης.
- **Ημερολόγιο**: μηνιαία εικόνα, χρώμα ανά τεχνικό, μετάθεση με σύρσιμο.
- **Ολοκλήρωση επίσκεψης**: εργασίες, κόστος, μετρήσεις καυσαερίων, Φύλλο Ελέγχου. Η επόμενη συντήρηση υπολογίζεται αυτόματα και μπορεί να κλειστεί αμέσως ραντεβού.
- **Μεταθέσεις**: κρατιέται ιστορικό με ημερομηνίες και λόγο.
- **Ρόλοι**: ο διαχειριστής κάνει τα πάντα· ο τεχνικός βλέπει τα πάντα και κλείνει/ολοκληρώνει τα δικά του ραντεβού.
- **Εξαγωγή** σε Excel (CSV) και αντίγραφο ασφαλείας (JSON).

## Αρχεία

| Αρχείο | Τι είναι |
|---|---|
| `supabase/schema.sql` | Η βάση δεδομένων: πίνακες, δικαιώματα, αυτοματισμοί |
| `js/config.js` | Οι ρυθμίσεις σας (διεύθυνση Supabase, κατηγορίες, χάρτης) |
| `js/app.js`, `css/app.css`, `index.html` | Η εφαρμογή |
| `manifest.webmanifest`, `sw.js`, `icons/` | Εγκατάσταση στο κινητό σαν εφαρμογή |

## Εγκατάσταση

1. **Supabase**: νέο project στο supabase.com (περιοχή Frankfurt). Στο *SQL Editor* τρέξτε όλο το `supabase/schema.sql`.
2. **Εγγραφές χρηστών**: στο *Authentication* απενεργοποιήστε τις ελεύθερες εγγραφές (*Allow new users to sign up*), ώστε λογαριασμούς να φτιάχνετε μόνο εσείς.
3. **Ο δικός σας λογαριασμός**: *Authentication → Users → Add user → Create new user*, με *Auto Confirm User*. Ο πρώτος λογαριασμός γίνεται αυτόματα διαχειριστής.
4. **Κλειδιά**: από *Project Settings → API Keys* αντιγράψτε το *Project URL* και το *Publishable key* στο `js/config.js`.
5. **GitHub Pages**: ανεβάστε όλα τα αρχεία σε ένα repository και ενεργοποιήστε *Settings → Pages → Deploy from a branch (main, / root)*.
6. **Σύνδεσμοι email**: στο Supabase *Authentication → URL Configuration* βάλτε ως *Site URL* τη διεύθυνση του GitHub Pages (χρειάζεται για το «Ξέχασα τον κωδικό»).
7. Στο κινητό ανοίξτε τη διεύθυνση και επιλέξτε *Προσθήκη στην αρχική οθόνη*.

Νέος τεχνικός: *Authentication → Users → Add user* στο Supabase. Εμφανίζεται αμέσως στις Ρυθμίσεις της εφαρμογής, όπου του αλλάζετε ρόλο, χρώμα ή τον απενεργοποιείτε.

## Ασφάλεια

Ο κώδικας στο GitHub δεν περιέχει δεδομένα. Το publishable key είναι δημόσιο από τη φύση του· τα δεδομένα τα προστατεύουν οι κανόνες της βάσης, που επιτρέπουν πρόσβαση μόνο σε ενεργούς χρήστες που φτιάξατε εσείς.

## Ενημέρωση

Το `schema.sql` ξανατρέχει με ασφάλεια. Μετά από αλλαγές στα αρχεία της εφαρμογής, αυξήστε το `?v=1` στο `index.html` ώστε τα κινητά να πάρουν αμέσως τη νέα έκδοση.
